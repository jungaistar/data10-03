## 7. 한계와 남은 일

- 업무 자료(도면 · 정답 · 측정 기록)는 아직 팀 공유 DB 가 아니라 각자의 브라우저에 저장합니다.
- 스캔 그림 도면은 읽지 못합니다(OCR 없음).
- 풍선 PDF 는 원본 쪽을 그림으로 넣고 풍선만 벡터입니다. 원본 벡터를 그대로 두는 편집은 하지 않습니다.
- 규칙 기반이라 회사 도면 양식 · 글꼴이 다르면 맞춰야 합니다. 실제 도면 일치율은 다음 도면에서 다시 낮을 수 있습니다.
- 남은 틀림 — 용접 형상 연결 · No Weld · PCD 등은 아직 고치지 않았습니다.
- 로그인 뒤 화면(게시판 · 관리 · 첫 화면 고르기)은 가짜 Supabase 로 화면 흐름을, 로컬 PostgreSQL 과 과정용 프로젝트에서 SQL 권한을 확인했습니다. 실제 계정으로 로그인해 누르는 확인은 요청자 몫입니다.
- 독립 운영까지 남은 것: 본인 Supabase 프로젝트에 auth.sql · board.sql · site.sql 실행 → js/auth-config.js 의 url · anonKey 교체 → 다시 배포(supabase/README.md)
